ברוכים הבאים

מערכת לניהול ומעקב ציוד — בחרו פעולה וקבלו תשובה מהמערכת.

המערכת מרכזת נתוני ציוד, חיילים, יחידות והחזרות במקום אחד.

הסבר לימודי: הכפתורים מפעילים קריאות API שמחזירות נתונים מתוך Views שנבנו בשלב ד׳ (v_soldier_resource_overview, v_unit_resource_summary).

מה מצב הציוד אצל החיילים?

תמונת מצב מרוכזת של ציוד, נשק ותחמושת לכל חייל.

מה מצב הציוד ביחידות?

סיכום כוח אדם, ציוד ונשק לכל יחידה במערכת.

צפייה במידע קיים

עיון ברשימות המידע — חיילים, יחידות, ציוד ועוד.

שאלות ותשובות מהנתונים

שאלו שאלה וקבלו תשובה מסוכמת מתוך הנתונים.

צפייה במידע

בחרו רשימה להצגה — המערכת תציג את המידע הקיים בה.
